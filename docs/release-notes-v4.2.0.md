ServicePilot 4.2.0 让大量本地服务更容易查找，也让启动结果可以主动到达用户：合并函数现在能发送 Windows 通知，托盘菜单可以直接输入服务名筛选。同时修复模板分享、日志折叠和单文件界面的几个可靠性问题。

## 新功能

- **合并函数系统通知**：动作的 C# 日志合并函数可以调用 `Notify("通知文字")`，在识别到 API、前端或其他服务启动完成时主动发送 Windows 通知。日志窗口关闭时仍有效；历史回放与 `merge-script test` 只预览请求，不会误弹通知。同一动作可通过 `State` 实现每轮启动只提醒一次。
- **托盘服务即时筛选**：右键打开托盘菜单后，搜索框自动聚焦，可以直接输入服务名过滤长列表。搜索框和底部管理入口保持固定，按向下键可以进入第一个匹配服务。

## 修复

- **模板交换保留日志行为**：导出、分享和重新导入服务模板时，动作的 `LogMergeScript` 会完整保留，日志折叠、进度摘要和启动通知不再丢失。
- **持续输出的末尾折叠区自修复**：增量更新后会核对实际折叠区，发现末尾几行游离在折叠组外时自动重建并恢复原有展开/折叠状态。
- **单文件日志窗口异常修复**：关闭 AvalonEdit 可选的输入时隐藏鼠标指针功能，避免鼠标进入日志或脚本编辑器时出现 `System.Windows.Forms` 找不到的错误弹窗。
- **透明图标边缘优化**：PNG 与 ICO 使用完整透明画布和预乘 Alpha 缩放；窗口任务栏图标直接使用透明 PNG，减少 Windows 深色任务栏上的亮边。

## 要求

- Windows
- 使用发布页自包含 `ServicePilot.exe` 时不需要单独安装 .NET 运行时。

## 安全说明

- ServicePilot 会执行用户配置的本地脚本；合并脚本同样是用户提供的 C# 代码，运行在应用进程内，请只使用你信任的合并脚本。
- AI 帮助内容会包含本机 exe 绝对路径，只建议发送给可信个人 AI 助手。
