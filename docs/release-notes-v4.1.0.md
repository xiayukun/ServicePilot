ServicePilot 4.1.0 聚焦日志窗口体验与本地进程运行可靠性：日志标签可以独立关闭和清空，高频输出时的自动滚动与折叠交互更稳定，短命令的尾部日志和停止结果也更可信。

## 改进

- **可关闭动作日志标签**：日志标签按动作的稳定标识区分，同名动作不会混入同一标签。关闭一个动作标签会清除该动作已经保留的日志，但不会停止正在运行的动作；工具栏“清空”继续清除当前服务的全部日志。
- **日志窗口交互更稳定**：自动滚动会等待内容与折叠布局完成后再跳转到底部，降低高频输出时停在旧末尾的情况。摘要/展开按钮会跟随真实折叠状态，持续输出、搜索和切换标签后仍能正确反映下一步操作。
- **关闭按钮视觉修复**：动作日志标签的 × 关闭按钮使用透明背景，避免标签页出现不协调的背景块。
- **进程输出与停止更可靠**：进程完成或停止前会排空标准输出、标准错误和已排队的日志回调，降低短命令尾部日志丢失的风险；排空超时时会明确报告错误，不再把失败显示为成功停止。

## 要求

- Windows
- 使用发布页自包含 `ServicePilot.exe` 时不需要单独安装 .NET 运行时。

## 安全说明

- ServicePilot 会执行用户配置的本地脚本；合并脚本同样是用户提供的 C# 代码，运行在应用进程内，请只使用你信任的合并脚本。
- AI 帮助内容会包含本机 exe 绝对路径，只建议发送给可信个人 AI 助手。
